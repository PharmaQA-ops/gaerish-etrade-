# Gaerish E-Trade

Official website for Gaerish E-Trade.

## Business

Gaerish E-Trade is focused on trading products and materials,
including:

- Containers
- Aluminium
- Metals & Scrap
- Other Materials

## Website

This is currently a static website built using:

- CSS3
- JavaScript
